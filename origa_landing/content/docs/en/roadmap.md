# Roadmap

This page lists directions currently being worked on for Origa. **There are no committed dates** — items may shift, expand, or merge as development progresses. Treat this as a description of intent, not a promise.

## Additional platforms

Origa is currently available on Windows, Linux, macOS, Android, and the web. The next platform in active development is iOS.

## New exercise types

Current lessons cover recognition, recall, listening, writing, kanji reading, and grammar. Planned additions include:

- Reading longer passages with embedded vocabulary
- Manga-style reading with panel-by-panel text extraction
- Contextual sentence exercises
- Audio-only listening without text support
- Video-based listening

The goal is to extend the lesson format to handle longer and more contextual material, not just isolated cards.

## Social features

Planned additions include competitive and community-oriented features — for example, comparisons or shared challenges between learners. The shape of these features is not finalized.

## More interface languages

Origa currently ships with English and Russian interfaces. Work continues on additional languages to broaden access for learners whose native language is neither.

## What this roadmap does not promise

- Specific release dates.
- A guarantee that any listed item will ship in its current form.
- Features beyond what is listed here.

If a feature matters to you and you do not see it, the right channel is GitHub Issues or Discussions. Concrete requests shape priorities more than speculation.
