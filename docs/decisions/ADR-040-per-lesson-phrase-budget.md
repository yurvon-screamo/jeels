# ADR-040: Пер-урок лимит новых якорных фраз

- Статус: Принято
- Дата: 2026-08-21
- Контекст: PR «Умное пустое состояние урока + пер-урок лимит фраз»

## Контекст

До этого изменения новые якорные (interleaved) фразы ограничивались
**дневным** бюджетом:

```
budget = daily_new_limit × PHRASE_NEW_RATIO(2) − phrase_cards_studied_today
```

(`lesson_builder::compute_phrase_new_budget`). Лимит `daily_new_limit`
калибруется под новую лексику (`DailyLoad::new_cards_per_day`: 3–30), а
фразы состоят из уже известных слов — это reinforcement, а не новый
материал. Практический эффект: пользователь, сделавший урок утром, к вечеру
получал урок без новых фраз («голодание» вечерних уроков), потому что
бюджет был исчерпан утренним уроком.

## Решение

Бюджет новых якорных фраз становится **пер-урок** капом, производным от
нагрузки пользователя:

```rust
DailyBudget {
    new_cards_per_day,          // как раньше
    new_phrases_per_lesson,     // = new_cards_per_day × 2 (PHRASES_PER_NEW_CARD)
}
```

- Значение капа выбрано ровно в бывший дневной бюджет первого урока дня
  (`daily × 2 − 0`). Это даёт **математически точный паритет** поведения
  первого урока дня — нулевая дельта для пользователей с одним уроком в
  день; единственное изменение поведения — второй и последующие уроки того
  же дня получают полный allowance вместо исчерпанного дневного.
- `phrase_cards_studied_today` остаётся в `DailyHistory` как статистика,
  но больше не участвует в сборке урока.
- Механика `InterleavePicker` (due-фразы бесплатно, новые — из бюджета)
  не изменилась; источник allowance — единственное изменение.
- No-anchor (tail) фразы как были, так и остаются независимыми от этого
  бюджета (`TAIL_PHRASE_PER_LESSON = 5`).

## Честность об эффективности капа

Кап `daily × 2` является **связывающим ограничением преимущественно на
Minimal(6)/Light(12)/Medium(18)**. На Hard(30)/Heavy(42)/Maximum(60)
эффективный лимитер — структурная граница
`INTERLEAVED_PHRASES_PER_WORD(2) × якорные слова core` (≤ `MAX_LESSON_SIZE`
- favorites ≈ до 44 фраз): кап там редко или никогда не биндит. Цель капа —
нулевая дельта первого урока и отвязка от времени суток, а не «главный
ограничитель доли фраз» на высоких нагрузках.

## Альтернативы

- **Произвольная шкала капов (4/6/8/12/14/18)** — отвергнута: сокращала
  фразы первого урока дня на всех уровнях нагрузки (до −70% на Maximum),
  регрессия для самой массовой персоны, числа не выводились из домена.
- **Полное снятие лимита** — отвергнуто: пул готовых фраз конечен для
  данного состояния словаря; без капа фразы исчерпались бы быстрее по
  дням, а пустых дней не стало бы меньше.
- **Повышение ratio 2→5** — отвергнуто: меняет баланс первого урока дня
  и не решает дневную связность.

## Последствия

- Вечерние уроки больше не голодают по новым фразам.
- `KnowledgeSet::cards_to_lesson` принимает `DailyBudget` вместо
  `usize` — единственная точка конструирования
  `SelectCardsToLessonUseCase`; тесты используют `DailyBudget::new(n, cap)`
  / `with_daily_cards(n)`.
- Глоссарий: термин «Дневной бюджет [DailyBudget]».
